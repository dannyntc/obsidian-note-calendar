# Changelog

## 0.1.0 — 2026-10-20

- Added the Note Calendar plugin with monthly calendar rendering.
- Added right-click toggling for Markdown notes.
- Added dated Markdown entries linked from calendar cells.
- Added calendar settings, entry indexing, and conflict handling.

## 0.2.0 — 2026-10-20

- Replaced right-click toggling with a calendar button in Markdown note headers.
- Kept the command palette toggle available.

## 0.3.0 — 2026-10-20

- Moved the calendar backlink to the first body row of new entries.
- Added three blank body rows and placed the editor cursor on the fifth body row.

## 0.4.0 — 2026-10-20

- Added a mobile single-column calendar layout for Android-sized screens.
- Hid adjacent-month filler days on mobile and added touch-friendly controls.
- Wrapped long entry names so mobile notes scroll vertically without horizontal panning.
